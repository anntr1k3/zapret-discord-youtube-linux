# Приёмка установленного GUI

Офлайн-тесты и VM-сценарии с прямым вызовом помощника не проверяют
графический агент polkit. Для этого нужна одноразовая Ubuntu VM с рабочим
графическим сеансом обычного пользователя и действующим агентом polkit.
Не запускайте само окно от root.

1. Установите проверяемый `.deb` и запишите его SHA-256. Не запускайте
   ручной `nfqws`. До открытия окна проверьте, что сервис отсутствует.
2. Откройте `zapret-gui`. Нажмите «Установить системный сервис…», подтвердите
   действие в окне Zapret и отмените **диалог polkit**. GUI должен показать
   отказ, без уведомления об успехе. Не должны появиться unit или
   `/etc/zapret-discord-youtube/conf.env`.
3. Повторите установку с авторизацией и ALT12. Проверьте, что GUI показывает
   установленный сервис. Запишите SHA-256 системного `conf.env` и удалите
   только сервис, **не** отмечая удаление данных.
4. Запустите GUI заново, повторите попытку установки и отмените именно
   авторизацию. SHA-256 `conf.env` должен быть прежним; сервис не должен
   запускаться. Подтвердите повторную установку и проверьте сохранённый ALT12.
5. Откройте desktop-действие «Тестировщик стратегий». Оно должно открыть
   настоящую вкладку без баннера демо, без запуска теста и без запроса пароля.

Для каждого шага отметьте результат, дистрибутив и тип сеанса. Отсутствие
агента или невозможность вызвать диалог — **не** успешная проверка отмены.
Не сохраняйте пароли и не публикуйте полные журналы VM.

Доступность видео YouTube, голоса Discord и QUIC — отдельная пользовательская
приёмка. Успешный запуск `nfqws` и создание nftables-правил её не заменяют.

## Пользовательские проверки сети

Проводите в согласованном окружении, где проблема наблюдается без сервиса.
NAT одноразовой VM и сеть хоста могут давать разные результаты. Не меняйте
сетевые настройки хоста ради проверки без отдельного согласия.

| Сценарий | Что сравнить с исходным состоянием | Что считать подтверждением |
| --- | --- | --- |
| YouTube | Один ролик и одинаковое качество в одном браузере; воспроизведение и перемотка | Видео запускается, не зависает при перемотке и воспроизводится несколько минут без повторных остановок. |
| Discord | Тот же клиент и голосовой канал с согласным участником | Канал подключается, звук слышен в обе стороны; соединение держится несколько минут. |
| QUIC | Для фактических запросов видео проверить колонку Protocol в инструментах разработчика браузера | Наблюдается `h3` на запросах медиаданных. Воспроизведение только через `h2` не подтверждает QUIC. |

Запишите версию артефакта и SHA-256, дистрибутив, клиент, профиль ALT12,
исходный результат и результат с сервисом. Если проблема не
воспроизводится без сервиса, отметьте «не удалось сравнить», а не «обход
подтверждён». Не публикуйте токены, идентификаторы аккаунтов, адреса
приватных каналов и сетевые журналы целиком.
