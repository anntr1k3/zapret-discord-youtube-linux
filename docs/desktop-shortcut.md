# Горячая клавиша остановки

Команда для пользовательской горячей клавиши GNOME:

```sh
python3 "$HOME/zapret-discord-youtube-linux/src/desktop/stop_service.py"
```

Для установленной через `install.py` новой версии можно использовать стабильный
системный путь (сначала обновите установленную копию, если файла ещё нет):

```sh
python3 /opt/zapret-discord-youtube/current/src/desktop/stop_service.py
```

Скрипт останавливает только `zapret_discord_youtube.service`, показывает
уведомление и не отключает автозапуск. Он не завершает ручной запуск
`service.sh run`: для него используйте Ctrl+C в соответствующем терминале.

Права запрашиваются стандартным механизмом systemd/polkit. В рабочем столе
может появиться диалог авторизации; пароль не хранится, NOPASSWD-правила не
создаются. Если авторизация отменена или сервис не установлен, успех не
показывается. Без графического polkit-агента используйте обычный терминал:
`sudo systemctl stop zapret_discord_youtube.service`.

Настройки GNOME: «Клавиатура» → «Просмотр и настройка комбинаций клавиш» →
«Пользовательские комбинации». Название: «Остановить Zapret»; команда указана
выше. Сочетание следует выбрать свободное, без замены существующей привязки
(например, `Ctrl+Alt+Z`). После установки новой версии через `install.py`
рекомендуется использовать стабильный путь из `/opt`, приведённый выше.

Проверить команду без остановки сервиса:

```sh
python3 src/desktop/stop_service.py --dry-run
```

Логика проверена с подменой subprocess; запись настроек GNOME прочитана обратно
и проверена. Сервис не останавливался при назначении сочетания. Изменения горячих
клавиш сами по себе не выполняются при установке/обновлении сервиса.
