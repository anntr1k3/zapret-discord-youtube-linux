# 🎧 Zapret Discord YouTube Linux — Релиз v1.0.0 📺

Полнофункциональный самостоятельный Linux-порт утилиты [Flowseal zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) с современным графическим интерфейсом на **GTK4 / libadwaita**, безопасной архитектурой разделения привилегий и **100% паритетом возможностей** оригинального Windows-скрипта `service.bat` версии **v1.10.4**.

---

## 🎯 Главная цель релиза 1.0

Обеспечить пользователям Linux максимально комфортный опыт обхода замедления и блокировок YouTube и Discord без необходимости использовать терминал для повседневных операций:
- Установка, запуск, остановка, автозапуск и удаление сервиса прямо из графического окна.
- Удобный выбор стратегий обхода DPI, настройка игровых портов Game Filter и режимов IPSet.
- Встроенный тестировщик стратегий в реальном времени с оценкой качества соединения.
- Глубокая локальная диагностика сетевых конфликтов (VPN, прокси, туннели).
- Безопасная очистка кэша Discord и обновление списков доменов и IPSet.

## 🛡️ Архитектура безопасности (Security Model)

В отличие от упрощённых скриптов, запускающих всё от `sudo`, данный проект спроектирован по принципу наименьших привилегий (Principle of Least Privilege):

1. **GUI никогда не запускается от root:**
   - Запуск `sudo python3 gui.py` аппаратно блокируется с понятным сообщением об ошибке.
   - Окно работает в непривилегированном пользовательском сеансе Wayland / X11.

2. **Изолированный привилегированный помощник:**
   - Все административные операции выполняются через строго контролируемый скрипт `/opt/zapret-discord-youtube/current/src/gui/privileged.py`.
   - Помощник вызывается через системный `pkexec` с запросом пароля пользователя (штатный диалог Polkit).
   - Помощник принадлежит root (права `0755`/`0644`), код из пользовательского рабочего каталога никогда не повышается до root.

3. **Защита чужих процессов:**
   - Остановка и перезапуск управляются исключительно через `systemd cgroup`.
   - Чужие или запущенные вручную процессы `nfqws` не завершаются слепыми командами вроде `killall nfqws` или `pkill`.

4. **Атомарность и автоматический откат:**
   - Перед изменением конфигурации создаются резервные копии.
   - Если после смены параметров служба не смогла запуститься, помощник автоматически восстанавливает прежнее состояние файлов и перезапускает службу.

5. **Безопасность сетевых проверок:**
   - Диагностика и baseline-тестирование стратегий выполняются без root-прав и не вмешиваются в работу сети.
   - Пароли прокси-серверов и учётные данные маскируются в отчётах диагностики.

## 🎨 Интеграция с рабочим столом (Desktop Integration)

- **Ярлык:** стандартный `.desktop`-файл с категорией `Network;GTK;`, ключевыми словами на русском и английском языках (`запрет`, `discord`, `youtube`, `dpi`, `vpn`).
- **Иконка:** векторная SVG-иконка в стиле современного GNOME Adwaita (стилизованный щит с градиентом от YouTube Red к Discord Blurple и молнией обхода DPI).
- **Скрипт быстрой установки:**
  ```bash
  # Установка ярлыка и иконки для текущего пользователя:
  ./src/desktop/install-desktop.sh --user

  # Либо для всех пользователей системы (требуются права root):
  sudo ./src/desktop/install-desktop.sh --system
  ```

## 🚀 Быстрый старт

### Требования к системе:
- Дистрибутив Linux с `systemd` (Ubuntu 22.04/24.04+, Debian 12+, Arch Linux, Fedora, Linux Mint и др.).
- Python 3.9+ с библиотеками PyGObject (`python3-gi`, `gir1.2-gtk-4.0`, `gir1.2-adw-1`).
- Бэкенд фильтрации: **nftables** (рекомендуется) или **iptables + ip6tables**.

### Запуск графического интерфейса:
```bash
# 1. Безопасный демо-режим (симуляция без изменения системы):
python3 gui.py --demo

# 2. Настоящий режим:
python3 gui.py
```

В открывшемся окне нажмите **«Установить системный сервис…»**, выберите предпочтительную стратегию (например, `general.bat` или `general_alt.bat`) и подтвердите установку в диалоге Polkit.
